# Custom PCA-25 engine ("G25 engine") — stage report, 2026-11-05

Naming per docs: the native system is **PocketDNA PCA-25**. It is not Global25,
its coordinates must not be mixed with public G25 references, and the optional
G25 prediction adapter remains a later, separate step (BIOINFORMATICS §14.9).

## Where the timed-out task had stopped

Experimental basis fitted with smartpca (2,829 basis samples, 99,794 markers,
25 PCs) and projection already validated: Python and TypeScript least-squares
projection match smartpca at max abs error ~6e-7 (tolerance 2e-6), on both full
calls and a demo marker-mask (masked-vs-full shift: median 0.05 training SD,
p95 0.18, on 16 held-out reference samples). Artifacts in
`dataset/interim/reference-validation/experimental-pca/` (gitignored).

## Built this session

1. **Portable bundle exporter** — `research/export_pca25_bundle.py` writes
   `bundle-v1/` (markers.tsv, weights/means/normalization/coordinate-scales
   .f64, manifest.json with SHA-256 of sources and bundle files). It recomputes
   the arrays and asserts equality with the validated parity-fixture weights
   before writing. Basis ID: `pocketdna-pca25-experimental-v1`.
2. **Runtime projection** — `src/features/ancestry/pca25.ts`: bundle shape
   validation, QC (call count, usable-marker floor of 5,000 marked provisional),
   projection via the existing Givens-QR solver, returns coordinates + usable
   markers + call rate.
3. **Mixture solver** — `src/features/ancestry/mixture.ts`: nonnegative,
   exactly sum-to-one era-mixture fit mirroring `backend/pipeline/engine.py`
   `fit_weights` semantics (active-set KKT; convergence checks copied).
   Solver only — no era source panel is bundled; panels need POPLIST approval.
4. **Tests** — `tests/pca25.test.ts` verifies every bundle checksum, then
   projects the 16 held-out samples from the exported bundle (full: max error
   6.02e-7; masked: 6.31e-7 vs smartpca) and asserts QC rejections.
   `tests/mixture.test.ts` recovers known synthetic mixtures to <1e-6,
   vertex and noisy cases included. `npx tsc --noEmit` clean; Python suite
   34 passed.

## Honest limits (unchanged gates)

- Basis is experimental: identity resolution and frozen-cohort work in
  BIOINFORMATICS §14 steps 2–3 are not closed; consumer-chip transfer is a
  marker-presence proxy on 16 reference samples, not real consumer exports.
- Coordinate scales are fitted on 16 basis individuals (documented in bundle).
- Consumer allele harmonization to the bundle's a1-count convention is not yet
  built; personal raw-DNA results therefore remain disabled in the product.
- Next stages: real consumer-export mask tests (§14.6), era source panels +
  bootstrap ranges (§14.7), then — only after native correctness — the
  optional G25 adapter (§14.9).

Self-score: 8/10. The engine core (basis → bundle → projection → mixture) is
now complete and oracle-verified; the science gates around it are reported,
not papered over.
